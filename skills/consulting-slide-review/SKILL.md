# Slide review v2
Use the supplied v2 standard where available. Check exactly one English 16:9 slide, action title <=20 words and <=2 lines, <=3 MECE blocks, around <=100 running words, visual anchor for each block, >=3 visual objects across >=2 types, hero chart >=1/3 body, >=5 points OR >=3 series per chart, annotation on each chart, key-figures strip and decision/number-led so-what. Check badge, runner, palette, grid, 0.5-inch margins, body/chart >=10 pt, all text >=9 pt, source notes, readability and no clipping or unintended overlap. Trace values, calculations and assumptions; verify datasheets, Appendix Note, mode and editability separately from actual think-cell objects. Use Pass / Fail / Not checked with evidence and prioritised corrections. Missing data or unverified Library names must be flagged, never fabricated. Do not claim render or file inspection if unavailable. Do not modify the slide unless asked.
