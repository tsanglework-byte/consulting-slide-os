# Universal consulting slide design
Read [the original Universal Consulting Slide Prompt v2](references/universal-slide-prompt-v2.md) in full before every design task. It is the sole design authority; this wrapper operationalises it without rewriting it. Read the current slide brief and use [the brief template](assets/slide-brief.md) for missing inputs. Do not apply the superseded V5.0 standard.

## Workflow
1. Identify the audience, decision, evidence, units, periods, sources and requested output mode. Use only supplied data. Mark missing values and list Data to confirm. Never fabricate data, template names or appendix references.
2. Choose one governing conclusion, action title (max 20 words, two lines), up to three MECE content blocks, about 100 words of running text maximum and a decision/number-led so-what. All slide text is professional English.
3. Follow the visual-first requirements in the original prompt: every block anchored by a chart/diagram; hero chart at least one third of body; at least three visual objects across at least two types; every chart annotated; five data points or three series per chart where source data supports it; key-figures strip, compact captions, sources and footnotes. Use [exhibit selection](references/exhibit-selection.md) and the original composition recipes. Do not force extra unsupported data or invent a quantitative chart for qualitative material. Report any unmet rule explicitly, and propose the closest honest alternative.
4. Use the original 16:9 grid, 0.5-inch margins, badge, logo placeholder, runner, header pills, palette and font sizes unless the brief overrides permitted brand/section settings. Do not let a third-party engine replace the style.
5. Produce exactly one slide in the selected mode: IMAGE, BLUEPRINT or PPTX. Follow [production](references/production.md). If the mode is missing, clarify or state the assumed mode. Never silently substitute a flattened image for editable PPTX. Always deliver the [build sheet](assets/build-sheet.md), Appendix Note, Data to confirm (if any) and Quality Check outside the slide. BLUEPRINT also needs Layout Choice, exact zone-by-zone English copy and 40–60-word Speaker Notes. Appendix Note is text, not a second slide.
6. Apply [quality gate](references/quality-gate.md). Render and inspect if available; record Pass / Fail / Not checked for each rule with evidence or reason. Fix what can be fixed without compromising source integrity. Report remaining conflicts, uncertainty, unsupported modes and verification status; rationale outside the slide in Vietnamese unless requested otherwise.

## Optional engine
Use ppt-master only if installed, reviewed, authorised and supported. Read its actual local instructions. Never silently install software, run unreviewed third-party scripts, publish files or expose private data. A native PowerPoint chart is not necessarily a think-cell object. Exact Library folder/template names must be verified against supplied references or the installed Library; if unavailable, label the suggested template/path unverified and give a native-shape fallback.
