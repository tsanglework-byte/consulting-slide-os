# Project instructions for Claude Code
For single-slide creation or revision use the consulting-slide-design skill. The canonical instructions are in `skills/consulting-slide-design/SKILL.md` and its original Universal Consulting Slide Prompt v2 reference. Follow the setup guide to install skills for discovery. Use specialist skills only for isolated steps. Do not auto-install dependencies, change master rules or publish changes without permission. Keep private data out of Git and report actual validation status.

For Excel financial modelling tasks, use `skills/financial-modelling/SKILL.md` and its original v2 financial modelling reference instead of the consulting-slide-design workflow. Do not invoke slide skills unless a slide is separately requested.
